# 🟢 LINE Sticker Studio Pro (LINE Creators Market Tool)

เว็บแอปพลิเคชันสร้างด้วย **Python Streamlit** สำหรับช่วยเตรียมไฟล์รูปภาพเพื่อทำสติกเกอร์ส่งขายบน **LINE Creators Market** แบบครบวงจร อัตโนมัติ แม่นยำ และป้องกันการโดน LINE ปฏิเสธ (Reject)
**💯 สายฟรี 100% — รันบนเครื่องของคุณเองแบบ Local ออฟไลน์ ไม่มีการเชื่อมต่อ External API หรือเสียค่าบริการใดๆ ทั้งสิ้น!**

---

## ✨ ฟีเจอร์หลักในระบบ (Comprehensive Features)

### 1. 🎨 สตูดิโอทำสติกเกอร์ (Sticker Studio)
- **Drag & Drop:** ลากไฟล์รูปภาพมาวางได้พร้อมกันหลายไฟล์ (`.png`, `.jpg`, `.jpeg`, `.webp`)
- **🚀 Super Upscale & Detail Restoration:** ขยายภาพขนาดเล็กด้วย Super-sampling + ลบรอยแตกพิกเซล (Anti-aliasing) + ฟื้นฟูเส้นขอบการ์ตูนให้คมกริบ ไม่แตกเป็นเหลี่ยม
- **🪄 ลบพื้นหลัง AI (`rembg`):** ตัดฉากหลังเป็น Transparent PNG คุณภาพสูง พร้อมโหมด Alpha Matting เก็บรายละเอียดขอบ
- **⚪ เพิ่มขอบขาวสติกเกอร์ (Die-cut Outline):** ช่วยให้มองเห็นสติกเกอร์ได้ชัดเจนทั้งใน Light Mode และ Dark Mode ของ LINE
- **📏 เว้นระยะขอบ Margin 10px อัตโนมัติ:** คำนวณจากขอบเนื้อหาจริง ป้องกันการโดน LINE Reject
- **📐 บังคับขนาดพิกเซลเลขคู่:** ความกว้างและความสูงเป็นเลขคู่เสมอตามกฎตายตัว

### 2. 🔢 ตารางจัดเรียงชุด & เลือก Main / Tab (Grid Manager)
- **แสดงภาพเป็นตาราง Grid:** พร้อมลำดับตัวเลข `01.png`, `02.png`, ...
- **เลื่อนสลับตำแหน่ง:** ปรับลำดับภาพก่อน-หลังได้อิสระ
- **⭐ ปุ่มคลิกเดียว "เป็น Main Image":** เลือกภาพหน้าปกชุดสติกเกอร์ (ขนาด 240 x 240 px)
- **🔖 ปุ่มคลิกเดียว "เป็น Tab Image":** เลือกภาพแท็บไอคอนห้องแชท (ขนาด 96 x 74 px)
- **ตัวนับชุดสติกเกอร์:** ตรวจสอบความถูกต้องของจำนวนตามเกณฑ์ LINE (8, 16, 24, 32 หรือ 40 รูป)
- **ดาวน์โหลดชุด ZIP:** รวมไฟล์ครบเซ็ตพร้อมตั้งชื่อตามมาตรฐาน LINE พร้อมนำไปอัปโหลดขายทันที

### 3. 🖌️ แปรงรีทัชลบ/กู้คืนส่วนที่ขาด (Touch-up Brush)
- **🧹 ยางลบ (Eraser):** ระบายลบเศษฝุ่นหรือขอบส่วนเกินที่ AI ตัดไม่หมดให้โปร่งใส
- **🖌️ พู่กันกู้คืน (Restore Brush):** ระบายดึงเนื้อหาจากภาพต้นฉบับกลับมา (แก้ปัญหา AI เผลอลบส่วนสีขาวของตัวละคร เช่น ตาขาว หรือเสื้อผ้าสีขาว)
- **ปรับขนาดหัวแปรง:** 3 - 50 px ใช้งานสะดวกและลื่นไหลบนเบราว์เซอร์

### 4. 🎞️ สติกเกอร์เคลื่อนไหว (Animated APNG Converter)
- **นำเข้า GIF หรือรูปภาพหลายเฟรม:** แปลงเป็นไฟล์ **APNG (.png)** อัตโนมัติ
- **คุมสเปกตามกฎเหล็กของ LINE:**
  - ขนาดกว้าง ≤ 320 px, สูง ≤ 270 px (เลขคู่เสมอ)
  - ความยาวการเล่นเป็นเลขจำนวนเต็ม 1, 2, 3 หรือ 4 วินาที
  - จำนวนเฟรม 5 ถึง 20 เฟรม
  - บีบอัดขนาดไฟล์ **ไม่เกิน 300 KB** (307,200 bytes)
- **พรีวิวการเล่นสด:** ดูตัวอย่างแอนิเมชันพร้อมผลการตรวจสอบ Audit

### 5. 📱 จำลองห้องแชท LINE เสมือนจริง (Live Chat Simulator)
- **สมาร์ทโฟนจำลอง:** สภาพแวดล้อมหน้าจอแชท LINE
- **สลับธีมได้ 4 รูปแบบ:** ธีมมาตรฐานสีฟ้า (Chat Blue), โหมดมืด (Dark Mode), มินิมอลขาว, ชมพูพาสเทล
- **ถาดสติกเกอร์:** คลิกที่สติกเกอร์เพื่อทดลองส่งเข้าห้องแชทจำลองได้ทันที (รองรับทั้งภาพนิ่งและภาพเคลื่อนไหว APNG)
- **พิมพ์ข้อความคุย:** พิมพ์ข้อความภาษาไทยโต้ตอบควบคู่กับสติกเกอร์ได้จริง

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Quickstart)

### ขั้นตอนที่ 1: ติดตั้งไลบรารี
```bash
pip install -r requirements.txt
```

### ขั้นตอนที่ 2: เริ่มต้นเว็บแอป
```bash
streamlit run app.py
```
*หรือดับเบิลคลิกไฟล์ **`run.bat`** เพื่อเปิดใช้งานได้ทันทีบน Windows!*

เว็บแอปพลิเคชันจะเปิดขึ้นในเบราว์เซอร์ของคุณที่ `http://localhost:8501`
